Factorising
Quadratics

Разложение квадратного трёхчлена на множители — два метода: для \(a=1\) и для \(a\neq 1\). Полный разбор с примерами и практикой.

Общая форма · General form
$$ax^2 + bx + c = (px + q)(rx + s)$$
§1 · Что такое факторизация · What is Factorising

Основная идея · The Big Idea

Факторизация (factorising) — это обратная операция к раскрытию скобок (expanding). Мы представляем квадратный трёхчлен \(ax^2+bx+c\) в виде произведения двух скобок.

Проверка · Check your answer
expand back

Чтобы проверить ответ, раскройте скобки обратно (expand) — должен получиться исходный трёхчлен.

\((x+3)(x+4) \xrightarrow{\text{expand}} x^2+7x+12 \checkmark\)
Случай 1 · Case 1: \(a = 1\)

Простой метод — два числа

Найти два числа, которые в сумме дают b, а в произведении — c

\(x^2+bx+c\)

✓ Быстро · Fast

Случай 2 · Case 2: \(a \neq 1\)

Метод ac — разбиение среднего члена

Найти два числа, которые в сумме дают b, а в произведении — a·c

\(ax^2+bx+c\)

⚙ Требует ac-метода

§2 · Коэффициент \(a = 1\) · When \(a = 1\)
⚡ Метод «двух чисел» · Two-numbers method

Для \(x^2+bx+c\) нужно найти два числа p и q такие, что:

p + q = b (сумма = коэффициент при x)  ·  p × q = c (произведение = свободный член)

Тогда: \(x^2+bx+c = (x+p)(x+q)\)

Алгоритм · Algorithm

01

Определить a, b, c · Identify a, b, c

Записать коэффициенты трёхчлена.

\(x^2+9x+14 \Rightarrow a=1,\;b=9,\;c=14\)
02

Найти пары делителей c · Factor pairs of c

Перечислить пары чисел, произведение которых равно c. Не забыть об отрицательных!

14 → (1,14), (2,7), (−1,−14), (−2,−7)
03

Выбрать пару с нужной суммой · Pick the pair with sum = b

Из всех пар выбрать ту, сумма которой равна b.

2 + 7 = 9 ✓ → (x+2)(x+7)
04

Проверить раскрытием скобок · Check by expanding

\((x+2)(x+7) = x^2+7x+2x+14 = x^2+9x+14\) ✓

Примеры · Worked Examples (a = 1)
Пример 1 · Example 1
\(x^2+7x+12\)
①\(a=1,\;b=7,\;c=12\)определяем коэффициенты
②Делители 12: \((1,12),(2,6),(3,4)\)factor pairs of 12
③\(3+4=7=b\) ✓ → берём 3 и 4сумма = b
✓\(x^2+7x+12=(x+3)(x+4)\)
Пример 2 · Example 2 — отрицательный b
\(x^2-3x+2\)
①\(a=1,\;b=-3,\;c=2\)c > 0, b < 0 → оба числа отрицательны
②Делители 2: \((-1,-2)\) → \(-1+(-2)=-3\) ✓both negative
✓\(x^2-3x+2=(x-1)(x-2)\)
Пример 3 · Example 3 — отрицательный c
\(x^2+2x-15\)
①\(a=1,\;b=2,\;c=-15\)c < 0 → числа разных знаков
②Делители −15: \((5,-3)\) → \(5+(-3)=2\) ✓opposite signs
✓\(x^2+2x-15=(x+5)(x-3)\)
§3 · Коэффициент \(a \neq 1\) · When \(a \neq 1\)
⚡ AC-метод / Splitting the Middle Term

Для \(ax^2+bx+c\) найти два числа p и q такие, что:

p + q = b (сумма = b)  ·  p × q = a·c (произведение = a×c, не просто c!)

Затем разбить средний член \(bx\) на \(px + qx\) и вынести общие множители.

AC-метод: 4 шага · AC Method: 4 Steps

01

Найти a·c · Multiply a × c

Вычислить произведение крайних коэффициентов. Именно это произведение, а не просто c!

\(6x^2+x-2 \Rightarrow a\cdot c = 6\times(-2)=-12\)
02

Найти два числа p, q · Find p and q

Перебрать делители (a·c) и найти пару с суммой b.

−12: пара (4, −3) → \(4+(-3)=1=b\) ✓
03

Разбить средний член · Split the middle term

Заменить bx на px + qx (порядок не важен).

\(6x^2+4x-3x-2\)
04

Вынести общие множители парами · Factorise in pairs

Сгруппировать попарно и вынести общий множитель. Скобка должна совпасть!

\(2x(3x+2)-1(3x+2)=(3x+2)(2x-1)\)
Примеры · Worked Examples \(a \neq 1\)
Пример 4 · AC-метод
\(3x^2+13x+4\)
①\(a=3,\;b=13,\;c=4\) → \(a\cdot c=3\times 4=12\)multiply a × c
②Делители 12: \((1,12)\) → \(1+12=13=b\) ✓find pair with sum = 13
③\(3x^2+x+12x+4\)split the middle term
④\(x(3x+1)+4(3x+1)\)factorise in pairs
✓\(3x^2+13x+4=(3x+1)(x+4)\)
Пример 5 · AC-метод — отрицательный c
\(6x^2+x-2\)
①\(a=6,\;b=1,\;c=-2\) → \(a\cdot c=-12\)a·c отрицательный
②\((4,-3)\): \(4+(-3)=1=b\) ✓ и \(4\times(-3)=-12\) ✓opposite signs, different values
③\(6x^2+4x-3x-2\)split: +4x and −3x
④\(2x(3x+2)-1(3x+2)\)factorise in pairs
✓\(6x^2+x-2=(3x+2)(2x-1)\)
Пример 6 · AC-метод — общий множитель сначала
\(6x^2-27x+30\)
⚠Сначала вынести общий множитель (GCF) = 3always check GCF first!
①\(3(2x^2-9x+10)\)factor out 3
②\(a\cdot c=2\times10=20\) → пара \((-4,-5)\): \(-4+(-5)=-9\) ✓ac-method on inner
③\(3(2x^2-4x-5x+10)=3[2x(x-2)-5(x-2)]\)split and pair
✓\(6x^2-27x+30=3(2x-5)(x-2)\)
§4 · Подсказка по знакам · Sign Guide

Как определить знаки в скобках?

Для случая a = 1 — простое правило по знакам b и c:

Знаки b и c Знаки в скобках Пример
\(b>0,\;c>0\) (+)(+) \(x^2+5x+6=(x+2)(x+3)\)
\(b<0,\;c>0\) (−)(−) \(x^2-5x+6=(x-2)(x-3)\)
\(b>0,\;c<0\) (+)(−) бо́льш.+ \(x^2+2x-15=(x+5)(x-3)\)
