Определение производной · Definition of Derivative
$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x)-f(x)}{\Delta x}$$
§1 · Определение и геометрический смысл · Definition

Что такое производная?

Производная функции \(f(x)\) в точке \(x_0\) — это предел отношения приращения функции \(\Delta y\) к приращению аргумента \(\Delta x\), когда \(\Delta x \to 0\).

Определение · Definition
limit
$$f'(x_0) = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$$
Геометрический смысл · Geometric meaning
tangent

Производная \(f'(x_0)\) — наклон (угловой коэффициент) касательной к графику в точке \((x_0,\,f(x_0))\).

\(\text{Уравнение касательной:} \quad y = f(x_0) + f'(x_0)(x - x_0)\)
\(\text{Уравнение нормали:} \quad y = f(x_0) - \dfrac{1}{f'(x_0)}(x - x_0)\)
Физический смысл · Physical meaning
physics
\(s'(t) = v(t)\) — мгновенная скорость (instant velocity)
\(v'(t) = a(t)\) — мгновенное ускорение (acceleration)
§2 · Применение · Applications

Где используют производную?

📈

Скорость изменения

Показывает, как быстро изменяется функция в данной точке.

🔍

Экстремумы

Максимум/минимум: \(f'(x)=0\) или \(f'(x)\) не существует.

📉

Монотонность

\(f'>0\) — возрастает; \(f'<0\) — убывает.

📐

Касательная

Уравнение касательной и нормали к кривой.

⚙️

Оптимизация

Задачи физики, экономики, инженерии.

∫

Связь с интегралом

Теорема Ньютона–Лейбница: \((F(x))'=f(x)\).

§3 · Свойства · Properties

Основные свойства производной

Линейность · Linearity
linear
\((af + bg)' = af' + bg', \quad a,b = \text{const}\)
\((C)' = 0\) — производная константы равна нулю
Power Rule · Степенная функция
power
\((x^n)' = n\,x^{n-1}\) — для любого вещественного \(n\)
\((x^2)'=2x, \quad (x^3)'=3x^2, \quad (\sqrt{x})'=\dfrac{1}{2\sqrt{x}}, \quad \left(\dfrac{1}{x}\right)'=-\dfrac{1}{x^2}\)
Непрерывность · Continuity
continuity

Если функция имеет производную в точке \(x_0\), то она непрерывна в этой точке. Обратное утверждение ложно.

§4 · Правила дифференцирования · Differentiation Rules
Сумма и разность · Sum & Difference
$$(u \pm v)' = u' \pm v'$$

Производная суммы (разности) = сумма (разность) производных.

Product Rule · Правило произведения
$$(uv)' = u'v + uv'$$

где \(u=u(x)\), \(v=v(x)\). Производная произведения двух функций.

Quotient Rule · Правило частного
$$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$$

где \(v \neq 0\). «Верхняя' × нижняя − верхняя × нижняя'» / нижняя².

Chain Rule · Правило цепочки
$$\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}$$

где \(y=f(u)\), \(u=g(x)\). Производная внешней × производная внутренней.

Обратная · Inverse function
$$\frac{dy}{dx} = \dfrac{1}{\;\dfrac{dx}{dy}\;}$$

Если \(y=f(x)\) строго монотонна и дифференцируема.

Что такое sec, csc (cosec), cot (ctg)? · Reciprocal functions
определение

Это обратные тригонометрические функции (reciprocal trig functions) — не путать с обратными (arcsin/arccos/arctan)!

\(\sec x = \dfrac{1}{\cos x}\) — секанс (secant). Не определён, когда \(\cos x = 0\)
\(\csc x = \operatorname{cosec}\, x = \dfrac{1}{\sin x}\) — косеканс (cosecant). Не определён, когда \(\sin x = 0\)
\(\cot x = \operatorname{ctg}\, x = \dfrac{\cos x}{\sin x} = \dfrac{1}{\tan x}\) — котангенс (cotangent). Не определён, когда \(\sin x = 0\)

Поэтому \((\sec x)' = \left(\dfrac{1}{\cos x}\right)'\) — можно вывести через правило частного → получим \(\sec x\tan x\).

Памятка · Reminder
chain rule

Для каждой формулы выше: сначала дифференцируем внешнюю функцию (оставляя \(u\) как аргумент), затем умножаем на \(u'\). Это и есть правило цепочки.

\(\bigl[f(u(x))\bigr]' = \underbrace{f'(u)}_{\text{внешняя}} \cdot \underbrace{u'}_{\text{внутренняя}}\)
§9 · Разобранные примеры · Worked Examples
Пример 1 · Правило цепочки — степень
\(y = 4(5x^3+2)^6\)
①Внешняя: \(u^6\), внутренняя: \(v=5x^3+2\)определяем структуру
②\(u'=24v^5,\quad v'=15x^2\)дифференцируем каждую
③\(y'=24(5x^3+2)^5\cdot 15x^2\)chain rule
✓\(y' = 360x^2(5x^3+2)^5\)упрощаем
Пример 2 · Корень от функции
\(y = \sqrt{9x-4}\)
①\(y=(9x-4)^{1/2}\), внешняя: \(\square^{1/2}\), внутренняя: \(9x-4\)записываем как степень
②\(y'=\tfrac{1}{2}(9x-4)^{-1/2}\cdot 9 = \dfrac{9}{2\sqrt{9x-4}}\)chain rule
✓\(y' = \dfrac{9}{2\sqrt{9x-4}}\)
Пример 3 · Логарифм от тригонометрии
\(y = \ln(\cos x)\)
①Внешняя: \(\ln(\square)\), внутренняя: \(\cos x\)шаблон \(\ln(g(x))\)
②\(y'=\dfrac{1}{\cos x}\cdot(-\sin x)\)\((\ln\square)'=1/\square\), \((\cos x)'=-\sin x\)
✓\(y' = -\dfrac{\sin x}{\cos x} = -\tan x\)упрощаем
Пример 4 · Правило произведения
\(y = x^2 e^{3x}\)
①\(u=x^2,\quad v=e^{3x}\)выделяем множители
②\(u'=2x,\quad v'=3e^{3x}\)дифференцируем каждый
③\(y'=u'v+uv'=2x\cdot e^{3x}+x^2\cdot 3e^{3x}\)product rule
✓\(y' = e^{3x}(2x+3x^2) = xe^{3x}(2+3x)\)выносим общий множитель
Пример 5 · Правило частного
\(y = \dfrac{\sin x}{x^2}\)
①\(u=\sin x,\quad v=x^2\)числитель и знаменатель
②\(u'=\cos x,\quad v'=2x\)
③\(y'=\dfrac{u'v-uv'}{v^2}=\dfrac{\cos x\cdot x^2-\sin x\cdot 2x}{x^4}\)quotient rule
✓\(y' = \dfrac{x\cos x - 2\sin x}{x^3}\)делим на x
Пример 6 · Reciprocal trig · 2a
\(y = \cot 4x\)
①Шаблон: \((\cot u)'=-\dfrac{u'}{\sin^2 u}\), где \(u=4x\)chain rule для ctg
②\(u'=(4x)'=4\)производная внутренней
✓\(y' = -\dfrac{4}{\sin^2 4x}\)подставляем
Пример 7 · Reciprocal trig · 2c
\(y = \csc 4x\)
①Шаблон: \((\csc u)'=-\csc u\cot u\cdot u'\), где \(u=4x\)chain rule для cosec
②\(u'=4\)производная внутренней
✓\(y' = -4\csc 4x\cot 4x\)подставляем
Пример 8 · Reciprocal trig · 2d — двойная цепочка
\(y = \sec^2 3x\)
①\(y = (\sec 3x)^2\) — внешняя: \(\square^2\), внутренняя: \(\sec 3x\)выделяем структуру
②Chain rule первый уровень: \(y'=2\sec 3x\cdot(\sec 3x)'\)power rule
③\((\sec 3x)'=\sec 3x\tan 3x\cdot 3\) — второй уровень цепочки\((\sec u)'=\sec u\tan u\cdot u'\)
④\(y'=2\sec 3x\cdot 3\sec 3x\tan 3x\)умножаем
✓\(y' = 6\sec^2 3x\tan 3x\)упрощаем
Пример 9 · Reciprocal trig · 3b — корень
\(y = \sqrt{\cot x}\)
①\(y=(\cot x)^{1/2}\) — внешняя: \(\square^{1/2}\), внутренняя: \(\cot x\)записываем как степень
②\((\cot x)'=-\dfrac{1}{\sin^2 x}\)производная cot x
③\(y'=\dfrac{1}{2}(\cot x)^{-1/2}\cdot\left(-\dfrac{1}{\sin^2 x}\right)\)chain rule
✓\(y' = -\dfrac{1}{2\sin^2 x\,\sqrt{\cot x}}\)отрицательный знак сохраняем
Пример 10 · Reciprocal trig · 3e — степень
\(y = \sec^3 x\)
①\(y=(\sec x)^3\) — внешняя: \(\square^3\), внутренняя: \(\sec x\)выделяем структуру
②\((\sec x)'=\sec x\tan x\)производная sec x
③\(y'=3(\sec x)^2\cdot\sec x\tan x\)chain rule: \(3\square^2\cdot(\sec x)'\)
✓\(y' = 3\sec^3 x\tan x\)упрощаем
Пример 11 · Inverse trig · 9b
\(y = \arctan\!\left(\dfrac{x}{2}\right)\)
①Шаблон: \((\arctan u)'=\dfrac{u'}{1+u^2}\), где \(u=\dfrac{x}{2}\)inverse trig chain rule
②\(u'=\dfrac{1}{2}\)производная \(\tfrac{x}{2}\)
③\(y'=\dfrac{\tfrac{1}{2}}{1+\left(\tfrac{x}{2}\right)^2}=\dfrac{\tfrac{1}{2}}{1+\tfrac{x^2}{4}}\)подставляем
④\(=\dfrac{\tfrac{1}{2}}{\tfrac{4+x^2}{4}}=\dfrac{1}{2}\cdot\dfrac{4}{4+x^2}\)общий знаменатель
✓\(y' = \dfrac{2}{4+x^2}\)упрощаем
Пример 12 · Inverse trig · 9c
\(y = \arcsin 3x\)
①Шаблон: \((\arcsin u)'=\dfrac{u'}{\sqrt{1-u^2}}\), где \(u=3x\)inverse trig chain rule
②\(u'=3\)производная \(3x\)
✓\(y' = \dfrac{3}{\sqrt{1-(3x)^2}} = \dfrac{3}{\sqrt{1-9x^2}}\)подставляем
Пример 13 · Inverse trig · 9h
\(y = \arccos x^2\)
①Шаблон: \((\arccos u)'=-\dfrac{u'}{\sqrt{1-u^2}}\), где \(u=x^2\)inverse trig chain rule
②\(u'=2x\)производная \(x^2\)
✓\(y' = -\dfrac{2x}{\sqrt{1-x^4}}\)подставляем \((x^2)^2=x^4\)
Пример 14 · Inverse trig + exp · 9l — двойная цепочка
\(y = e^{\arctan x}\)
①Внешняя: \(e^{\square}\), внутренняя: \(u=\arctan x\)выделяем структуру
②\((e^u)'=e^u\cdot u'\)шаблон exp
③\(u'=(\arctan x)'=\dfrac{1}{1+x^2}\)производная arctan x
✓\(y' = e^{\arctan x}\cdot\dfrac{1}{1+x^2} = \dfrac{e^{\arctan x}}{1+x^2}\)подставляем
